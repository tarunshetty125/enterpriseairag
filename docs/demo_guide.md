# Demo Guide

Use this flow for a 5-7 minute interview demonstration.

## 1. Executive Dashboard

Open the dashboard and explain that the system is an internal banking AI
platform, not a standalone chatbot. Point out customers, risk counts,
recommendations, knowledge base documents, AI requests, provider, model, and
recent reports.

## 2. Customer 360

Open the first customer from the dashboard. Walk through the tabs: Overview,
Features, Risk, Behaviour, Transactions, Recommendations, Policy Evidence, AI
Report, and Timeline.

## 3. Generate Customer Report

Click `Generate Customer Report`. Explain that the report composes the feature
store, ML models, NLP behaviour engine, recommendation engine, policy retrieval,
prompt manager, AI Gateway, and active provider.

## 4. Explainability

Show risk drivers, recommendation reasons, citations, retrieved chunks, token
usage, provider status, and workflow timing.

## 5. Exports

Export the report as Markdown, JSON, or PDF. Mention that exports preserve
citations for auditability.

## 6. Developer Console

Close with the Developer Console to show provider/model settings, token usage,
retrieved chunks, model versions, feature version, dataset version, SQLite size,
vector index size, and report cache hits.
