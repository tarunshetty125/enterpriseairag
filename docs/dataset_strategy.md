# Dataset Strategy

Phase 2 uses public datasets only and keeps raw files immutable.

## Sources

- Bank Customer Churn: public GitHub mirror of `Churn_Modelling.csv`.
- Loan Prediction: public GitHub mirror of the common loan prediction training CSV.
- Credit Card Customers: public GitHub mirror of `BankChurners.csv`, sampled locally for demo performance.
- PaySim: public Hugging Face mirror, sampled locally to avoid loading the full multi-million-row dataset.

## Storage

- `data/raw/`: cached source CSVs, never edited by code.
- `data/processed/`: normalized CSVs generated by ingestion.
- `data/external/`: reserved for manually supplied public datasets.
- `data/samples/`: reserved for small data samples.
- `data/policies/`: reserved for future policy PDFs.

Generated data files and the SQLite database are ignored by git.

## Ingestion Rules

The ingestion pipeline loads CSVs, validates required columns, normalizes column names, maps records into the canonical schema, stores metadata, and records ingestion runs. Running ingestion multiple times is idempotent because canonical entities are upserted by deterministic source identifiers.
