# Banking FAQ

## Customer Review

Relationship managers should review customer profile data, feature store values,
ML risk predictions, transaction behaviour, recommendations, and relevant policy
evidence before contacting a customer.

## Policy Assistant Scope

The assistant is restricted to banking policy and financial documentation
questions. It should cite retrieved documents and return "Insufficient
supporting documentation." when evidence is not available.

## Runtime Providers

The AI platform supports runtime provider switching. Provider choice affects
language generation only; ML models, feature store values, behaviour profiles,
and recommendation outputs remain the source of truth.
